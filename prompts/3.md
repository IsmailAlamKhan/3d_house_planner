# Prompt 3 — 2D Floor Plan Editor

## Goal
Build a clean, forgiving 2D plan editor (SVG-based) where users draw walls and rooms for the active level.

## Tasks
1. **Canvas**
   - Pan with middle-drag, space+drag, or two-finger drag. Zoom with the wheel or a pinch, centered on the cursor.
   - Show a grid with major and minor lines that adapt to zoom level.
   - Draw the shell footprint as a shaded boundary. Draw locked columns as solid hatched shapes.
   - Show other levels as faint "ghost" outlines (with a toggle) so users can align floors.
2. **Snapping** (toggle in the status bar)
   - Snap to the grid (configurable: 0.05 / 0.1 / 0.25 m).
   - Snap to wall endpoints and midpoints, perpendicular and parallel to existing walls, and 0/45/90° angles. Show snap indicators.
3. **Tools** (toolbar inside the 2D view, with keyboard shortcuts)
   - **Select (V):** click to select. Shift-click adds to the selection. Box-select. Drag to move. Drag wall endpoints, and connected walls follow.
   - **Wall (W):** click-click to draw a chain of walls, double-click or Esc to finish. Typing a number while drawing sets the exact length.
   - **Room (R):** draw a rectangle or polygon that creates walls *and* a room in one action.
   - **Measure (M):** a temporary dimension line.
   - **Delete:** the Delete or Backspace key.
4. **Room detection** (`src/geometry/rooms.ts`)
   - Build a planar graph from wall centerlines, splitting walls at intersections. Find the minimal closed faces and create or update `Room` polygons automatically. Keep user-set names and types when a room's shape changes slightly, by matching on overlap.
   - Show each room's name and area (m² or ft²) at the room's centroid.
5. **Dimensions:** show live length labels on walls while drawing and on selected walls. Add an optional toggle for all dimensions.
6. **Rendering:** draw walls as filled polygons with their real thickness, and clean the corner joins at shared endpoints using miter or butt joins from `src/geometry/walls.ts`. This join logic is reused in 3D.
7. **Properties panel:** when a wall is selected, edit its thickness, type, height, and materials. When a room is selected, edit its name, type, and floor material. The panel supports multiple selections for shared fields.
8. All edits go through store operations, so they are undoable.

## Acceptance criteria
- A user can draw a 4-wall rectangle and see a room detected with the correct area.
- A user can split a room with an interior wall and get two rooms.
- Snapping and typed exact lengths work.
- Unit tests cover the wall join geometry and room detection, including an L-shaped room and a room with an interior partition.
