# Prompt 19 — AI "Recreate From a Picture" (local vision model → reference spec)

## Goal
Make the AI helper able to produce a **1:1 layout from a picture**, not just a sentence. The user uploads a floor-plan image (such as `reference/villa-reference.png`). A **local vision model** reads room labels, sizes, and positions, and produces a `ReferenceSpec` (prompt 18). The user corrects it on the underlay, and the deterministic builder from prompt 18 creates the model. The solver is **not** used in this mode.

**Make this prompt idempotent.** Requires prompt 18.

## Tasks
1. **Vision model via Ollama** (free, local):
   - Default to a Qwen vision-language model that fits in 16 GB VRAM (for example the 7–8B Qwen VL model in the Ollama library). Check what Ollama currently offers, record the chosen tag in `.env.example` (`OLLAMA_VISION_MODEL`), and have `ollama-init` pull it.
   - All vision calls go through the existing GPU job queue (the vision model, `qwen3:14b`, and ComfyUI never share VRAM).
2. **Extraction pipeline** (`src/ai/vision/`):
   1. Rectify the image with the underlay homography from prompt 18 (the user marks 4 corners first, or accepts an automatic guess).
   2. **Pass 1: label reading.** Ask the model, with JSON-schema output, for every text label: its text, a parsed name and size (`14' x 12'` or `4.2 × 3.6 m`), and its approximate pixel position.
   3. **Pass 2: region boxes.** Split the rectified image into overlapping tiles (vision models are weak at precise geometry on large images). For each tile, ask for room and zone bounding boxes with their labels. Merge the results.
   4. **Geometry clean-up in code** (not by the model): snap boxes to a grid, align shared edges, close gaps under a threshold, and resolve overlaps. Fit each room to its label size (Option A) or to its pictured size (Option B).
   5. **Items pass (optional):** detect major furniture and outdoor features per room (bed, sofa, dining table, pool, cars, trampoline…) and map them to catalog ids.
3. **Review screen:**
   - Show the rectified picture with the extracted rooms overlaid, color-coded by confidence.
   - Provide a list of rooms with editable name, type, size, and position, and allow add or delete.
   - "Build exact" runs the prompt 18 builder. "Build as labelled" and "Build as pictured" create design options.
   - Nothing is applied without review.
4. **Evaluation:** add `npm run ai:eval:vision`. Use `reference/villa-reference.png` with a hand-checked ground-truth spec (from prompt 18) plus 4 simple synthetic plans the script renders itself, with known answers. Report label recall, size accuracy, and room position error (in ft). Record the results in PROGRESS.md.
   - Target on the reference villa: at least 90% of labels read correctly, and room centers within 3 ft before manual correction.
5. **Text briefs still work as before** (solver mode). In the AI tab, make the two modes clear: "Describe it" (creative layout) versus "Recreate from picture" (exact layout).

## Acceptance criteria
- On the GPU PC, uploading `reference/villa-reference.png` and accepting the extracted spec (with at most a few manual fixes) builds a villa matching the prompt 18 inventory.
- The eval results are recorded.
- No VRAM conflicts with other GPU jobs.
