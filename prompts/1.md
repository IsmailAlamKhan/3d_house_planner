# Prompt 1 — Project Setup & Architecture

## Goal
Create the project skeleton, tooling, app shell layout, and architecture document that every later prompt builds on.

## Tech stack (use exactly this unless impossible)
- Vite + React 18 + TypeScript (strict)
- `three`, `@react-three/fiber`, `@react-three/drei` for 3D
- `zustand` + `immer` for state, `zundo` for undo/redo (wired in prompt 2)
- `zod` for schemas
- Tailwind CSS for styling, `lucide-react` for icons
- `idb-keyval` (or Dexie) for IndexedDB persistence
- Vitest + Testing Library for unit tests, Playwright for smoke tests
- ESLint + Prettier

## Tasks
1. Scaffold the app. Add npm scripts: `dev`, `build`, `preview`, `typecheck`, `lint`, `test`, `test:e2e`.
2. Create this folder structure:
   ```
   src/
     app/          # App shell, layout, routing (if any)
     model/        # Data model types, zod schemas, store, operations
     geometry/     # Pure geometry utils (2D math, polygons, wall joins)
     plan2d/       # 2D floor plan editor
     scene3d/      # 3D scene generation & rendering
     catalog/      # Drag-and-drop component library (doors, windows, furniture)
     materials/    # Materials & textures
     ai/           # Prompt-to-model features
     export/       # Export features
     ui/           # Shared UI components (panels, buttons, dialogs)
     i18n/         # Translations
   docs/ARCHITECTURE.md
   PROGRESS.md
   ```
3. Build the app shell layout:
   - **Top bar:** project name, undo/redo buttons (disabled stubs for now), view switcher (2D / 3D / Split), and export menu (stub).
   - **Left sidebar:** tabs for "Library", "Levels", and "AI Assistant" (empty panels for now).
   - **Center:** a viewport area that can show 2D, 3D, or both side by side (Split view).
   - **Right sidebar:** a "Properties" panel (empty for now).
   - **Bottom status bar:** units, snap on/off, and cursor coordinates (placeholders).
   - The layout is responsive. On narrow screens, the sidebars collapse into drawers.
4. Render a basic 3D canvas: ground grid, orbit controls, ambient and directional light, and a test box. Render a basic 2D SVG canvas with a grid.
5. Set up i18n with simple key-based translation, English by default, structured so more languages are easy to add. Prompt 11 adds a second language.
6. Write `docs/ARCHITECTURE.md` covering the stack, the folder purposes, the single-source-of-truth rule (project JSON → 2D and 3D views), the meters/radians unit convention, and how future modules plug in.
7. Add one passing unit test and one Playwright smoke test that loads the app and checks that the 3D canvas exists.

## Acceptance criteria
- `npm run dev` shows the full layout with working 2D / 3D / Split switching.
- typecheck, lint, test, and build all pass.
- `docs/ARCHITECTURE.md` and `PROGRESS.md` exist.

## Out of scope
Real editing, the data model, and AI features.
