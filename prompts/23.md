# Prompt 23 — Enhance v2: Make AI Enhancement Actually Look Like the Reference

## Why
Today's Enhance runs SDXL img2img plus ControlNet over the app's raster render at 0.35 creativity, with a generic prompt. It can only restyle a weak source, so results look poor (PROGRESS.md, OPEN 2).

With prompts 20–22 done, the source is a good Studio render. Enhancement should now add **photographic polish and the reference's style**, without changing the layout.

**Make this prompt idempotent.** Extend the existing ComfyUI service, workflow, GPU queue, and gallery.

## Tasks
1. **Better source:** Enhance uses the latest **Studio render** (prompt 21) plus its depth and ID passes by default. The raster render is a fallback only.
2. **Style reference with IP-Adapter:**
   - Add ComfyUI IP-Adapter support for SDXL (the IPAdapter custom node pack, pinned to a commit, plus the SDXL IP-Adapter weights and CLIP vision encoder). Download them in `comfyui-init`, and record licenses.
   - The user can attach a **style reference image**. Default for the reference villa: `reference/villa-reference.png`.
   - Weight slider, defaulting to about 0.5–0.6.
3. **Checkpoint:** keep SDXL base 1.0 as the default. Optionally allow a realistic SDXL fine-tune, but only if its license allows the use, and document it. Make it selectable in settings.
4. **Region-aware prompting:** use the ID pass from Blender to build masks (pool and water, lawn and planting, interior floors, beds and soft furnishings, glass, cars, sky). Apply region prompts with ComfyUI masked conditioning ("crystal clear turquoise pool water with underwater lights", "lush tropical planting", "marble floor with soft reflections"…). Mask the label areas so the AI doesn't try to draw text.
5. **Layout lock:** use depth plus canny (or lineart) ControlNets at higher strength for walls and furniture edges. Add a **post-check**: compare the ID pass with a segmentation of the result (simple color clustering or an edge-overlap score). If walls moved too much, auto-retry with lower creativity, or warn the user.
6. **Resolution:** use a tiled upscale (for example the Ultimate SD Upscale node pack, pinned) to 2× or 3× with low denoise, so the final image is crisp at poster size. It must fit in 16 GB VRAM through tiling.
7. **Presets:** "Reference villa look" (IP-Adapter with the reference, dusk, creativity 0.25, depth 0.85, canny 0.6, region prompts on), plus "Subtle polish" and "Bold restyle". Show before and after next to the reference image in the Compare view.
8. **Quality evaluation** (`npm run eval:enhance`, GPU PC only):
   - Run the presets on 3 saved views of the reference villa.
   - Record time, VRAM, a layout-preservation score (edge overlap with the source), and a style similarity score (CLIP image similarity to the reference).
   - Save a contact sheet to `reference/renders/enhance-eval.png`.
   - Tune the defaults until the "Reference villa look" beats the old pipeline on both scores. Record the numbers in PROGRESS.md.

## Acceptance criteria
- On the GPU PC, Enhance with the "Reference villa look" turns the Studio render of the reference villa into an image that reads as the same villa in the same style as the reference.
- Labels stay crisp, and the layout doesn't drift.
- The eval numbers show improvement over the old pipeline and are recorded.
- Everything still fits the single-GPU queue with no out-of-memory errors.
