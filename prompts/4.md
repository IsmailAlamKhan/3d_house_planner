# Prompt 4 — 3D Model Generation From the Plan

## Goal
Generate a detailed 3D model live from the project JSON. Every 2D edit updates the 3D view instantly.

## Tasks
1. **Generators** (pure functions in `src/scene3d/generators/`: model → `BufferGeometry` plus material keys)
   - **Walls:** extrude each wall's footprint polygon (using the same join logic as 2D) up to the wall's height. **Openings:** build each wall as a `THREE.Shape` in wall-local coordinates with holes for its openings, then extrude it by the wall thickness. Don't use CSG. Give inner and outer faces separate material groups.
   - **Slabs and floors:** the floor slab of each level follows the shell footprint and has the slab thickness. Each room gets its own floor surface with the room's floor material. Upper levels get **voids** where stairs pass through and where rooms are marked `doubleHeight`.
   - **Ceilings:** generate them per room, and toggle them off in "dollhouse" view.
   - **Columns:** extruded boxes or cylinders.
   - **Stairs:** a procedural mesh for straight, L, U, and spiral types. Compute riser height from the level elevation difference (target 0.17–0.19 m) and choose a tread depth of at least 0.25 m. Add a railing if enabled. Validate that the stair fits, and warn if headroom is under 2.0 m.
   - **Door and window frames:** simple frame geometry in each opening. Doors get a leaf (rotated slightly open, with a toggle). Windows get a frame plus a transparent glass pane.
2. **Performance:** memoize the generators per entity (key on the entity plus its dependencies), so only changed parts rebuild. Dispose of old geometries when they are replaced.
3. **Scene:** place levels at their elevations. Clicking a mesh selects the underlying entity, which syncs with the 2D view and the Properties panel. Highlight the selection with an outline (drei `Outlines` or similar).
4. **View options:**
   - Show all levels, or only the active level plus the ones below it.
   - "Dollhouse" mode, which hides ceilings and the upper slab.
   - Walls up, walls cut at 1.2 m, or walls transparent.
5. Add a generator unit test for each entity type, checking geometry bounds and the number of holes for openings.

## Acceptance criteria
- The sample duplex renders with walls, openings, both slabs, a working stair void, and stairs.
- Editing in 2D updates 3D within one frame for small projects.
- Selecting in 3D selects the same entity in 2D.
