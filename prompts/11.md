# Prompt 11 — UX Polish, Onboarding & Accessibility

## Goal
Make the app feel finished and easy for first-time, non-technical users.

## Tasks
1. **Onboarding:** an optional interactive first-run tour (6–8 steps): shell wizard → draw or generate → drag furniture → change materials → walk through → export. It can be replayed from Help.
2. **Discoverability**
   - Tooltips with keyboard shortcuts on every tool.
   - A searchable command palette (Ctrl/Cmd+K) listing all actions.
   - A "?" shortcut sheet.
   - Empty states that suggest the next step, for example "No rooms yet — draw walls (W) or ask the AI Assistant".
3. **Comments and notes:** pin notes to a location or entity, such as "Ask about window size here". Show them in both views, and list them in a panel with resolve and delete actions. They are saved in the project.
4. **Design options:** let the user duplicate the current design as "Option A / Option B / Option C" within one project and compare two options side by side in synced 3D views.
5. **Internationalization:** complete the translations for all UI strings. Add **Bengali (বাংলা)** as a second language with a language switcher. Make sure Bengali text renders correctly by bundling a suitable font (for example Noto Sans Bengali, bundled locally) with proper fallbacks. Format numbers and units per locale.
6. **Theme and look:** light and dark themes, a consistent spacing and typography scale, smooth panel transitions, and clear loading and error states. Toasts appear for actions such as "Saved" and "Exported".
7. **Accessibility:** full keyboard operation of panels and dialogs, visible focus states, ARIA labels on icon buttons, color contrast at AA level, and a reduced-motion setting that respects `prefers-reduced-motion`.
8. **Mobile and tablet:** a touch-friendly toolbar, bottom sheet panels, and the gestures from earlier prompts verified on a phone-sized viewport in Playwright.

## Acceptance criteria
- A new user can complete the tour without errors.
- All UI strings switch between English and Bengali, with Bengali rendering correctly.
- The app is usable at a 390 × 844 viewport.
- Playwright smoke tests cover the tour and the language switch.
