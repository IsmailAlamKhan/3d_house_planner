# Prompt 9 — Camera, Navigation & Inspection Tools

## Goal
Make exploring the model easy and enjoyable for non-technical users.

## Tasks
1. **Camera modes**
   - **Orbit** (the default): damped orbit around the model, with focus-on-selection via double-click or the F key.
   - **Walkthrough:** first-person at eye height (1.6 m) on the active level. Use WASD or arrows plus mouse look, an on-screen joystick on touch devices, collision with walls, and automatic level change when walking up or down the stair. Esc exits.
   - **Top view:** an orthographic plan from above.
   - **Preset views:** Front, Back, Left, Right, and Isometric, with smooth animated transitions.
2. **Saved views:** save the current camera as a named view stored in the project, such as "Kitchen from living room". Show a strip of saved views with thumbnails.
3. **Section and cut tools**
   - A horizontal section height slider that cuts all levels at a chosen height.
   - A vertical section plane that can be dragged across the model.
   - Use clipping planes, with cap faces filled in a solid color.
4. **Isolation:** show a single level, show a single room (everything else ghosted), and an x-ray mode with transparent walls.
5. **3D measurement:** click two points on surfaces to measure distance, shown as a 3D dimension line with a label.
6. **Minimap:** a small 2D plan in a corner of the 3D view showing camera position and direction. Clicking it teleports the camera in walkthrough mode.

## Acceptance criteria
- Walkthrough mode lets a user walk from the entrance, up the stairs, into an upstairs bedroom without passing through walls.
- Section tools and saved views work and persist in the project file.
